# v2 方案：全代码渲染 + TTS 旁白

本方案替代 `01_横版3分钟_旁白与分镜.md` 的画面和旁白部分；`03_素材清单与事实核查.md` 里的核查项仍然有效。

## 一、总体思路

**节奏由音乐和代码时间轴决定，真实素材只做点缀，TTS 只负责讲述。**

- 先定配乐，量出节拍网格，所有剪辑点都落在节拍上。
- 画面全部由代码渲染，统一成「黑底金线」的视觉语言。真人一律经过风格化处理（线稿、粒子、剪影、数据复现），不出现原始写实画面的长镜头。
- 原版视频最多切 0.5–1.5 秒的高光瞬间，嵌进代码画面里（老电视框、票根窗口等），作为节奏里的"砸点"。
- TTS 只在克制、平静的段落讲故事；最燃的高潮段**完全不用 TTS**，交给音乐、现场声和文字。

## 二、视觉语言：黑底金线

参考爆款：vittorio 的《西方文明史》（黑底金色线稿，X 上约 1500 万播放）。

每个年代的线条颜色和底纹不同，但都在同一套语言里：

| 年代 | 线条 / 底纹 | 情绪 |
| --- | --- | --- |
| 1979–1989 | 旧金色线条 + 胶片颗粒 + 纸张纹理 | 怀旧、好奇 |
| 1990s–2019 | 金红线条 + CRT 扫描线 → 高清锐利线条 | 升温、辉煌 |
| 2019–2025 暂停 | 冷灰蓝细线，画面大量留黑 | 寂静 |
| 2025–2026 | 金线 + 全彩霓虹光效 + 粒子爆发 | 重逢、燃 |

## 四、TTS 策略：不让 TTS 去"燃"

TTS 最弱的是情绪爬升和嘶吼式高潮，最稳的是**低沉、克制的纪录片腔**。所以：

1. **分工**：TTS 负责第一到第三幕的讲述和第四幕开头的两句；高潮的最后约 25 秒不用 TTS。
2. **短句**：每句不超过 15 个字，句间留 0.3–0.8 秒停顿。长句是 TTS 跑调、拖腔的主要原因。
3. **反差**：结尾一句用平静、压低的声音，压在最响的音乐上。电影预告片常用这种处理，正好不需要 TTS 表演激情。
4. **引擎选择**（逐句生成，每句出 3 版挑最好的）：
   - 首选 **IndexTTS 2.5**：开源，情感和音色可以分开控制，`duration_factor` 能调句子时长，多音字可以直接写拼音。
   - 备选 **豆包 Seed-TTS 2.0 expressive**：用 `context_texts` 写画面式的情感提示，比如「深夜空荡的球馆里，低声回忆往事」。
   - 再备选 **MiniMax**：上手最快。
   - 避开剪映里那些被用烂的网红音色，以及 edge-tts。
5. **混音补偿**：
   - 语速约 0.9 倍，低频略微提升，让声音更厚。
   - 按场景加混响：传达室那段干声，球馆那段大空间混响。混响能掩盖 TTS 的"录音棚感"。
   - 旁白出现时音乐自动压低，旁白结束后音乐回升。
6. **真实声音放在最关键的位置**：2004 年现场观众喊「姚明」、2025 年的欢呼声，如果内部片库能调到原始音轨，比任何 TTS 都更有感染力。调不到的话，用授权的大型观众音效库代替。

## 五、配乐：全片最重要的一项投入

「恢弘」和「燃」主要来自音乐，不来自旁白。

- 用正版授权的史诗或预告片风格曲目（NBA 内部曲库，或 Artlist、Epidemic Sound 等商用曲库），要有明显的「铺垫 → 断点 → 爆发」结构。
- 不建议用代码合成配乐：电子小品可以，管弦乐的恢弘感做不出来。
- 让 Opus 用 Python 先「测」这首曲子：逐帧算能量、低音和节拍，存成节拍表，所有画面都读这张表来卡点（P(doom) MV 就是这么做的）。
- **先选曲，再定镜头时长**。下面的时间码是按「约 3 分钟、中段有一次断点」写的，选好曲子之后整体对齐。

## 八、制作流程（由 Opus 5.5 在 Claude Code 中执行）

1. **选曲**：人工选一首授权曲目 → Opus 用 Python 分析节拍、能量、断点，输出节拍表。
2. **配音**：Opus 调用 TTS 逐句生成、每句 3 版 → 人工挑选 → Opus 量出每句时长，写进时间轴。
3. **素材预处理**：拿到授权的照片和短片后，Opus 写脚本做线稿化（A）、半调网点（E）、深度分层（F）。
4. **样片**：先做最难的 10 秒，建议是 1:24–1:32 的「战术板 → 线稿扣篮 → 闪白」，确认视觉风格。
5. **全片渲染**：HTML/Canvas 场景中每一帧都是时间 t 的函数，无头浏览器逐帧截图，ffmpeg 合成，并混入音乐、旁白和音效。
6. **自检**：Opus 抽帧拼成缩略图总览，检查卡点、字幕和安全区；最后由人通看、通听一遍。
7. **竖版**：复用同一套场景代码，改成 9:16 画幅，按 `02` 号文件的结构重新排时间轴。
