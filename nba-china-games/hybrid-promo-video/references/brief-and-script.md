# 需求、查证与脚本

## 开工前必须问清的问题

一次问完，问不到的按默认值走，并在回复里写明用的是默认值。

| 问题 | 默认值 | 为什么要问 |
| --- | --- | --- |
| 有哪些版本、各多长 | 横版约 3 分钟 + 竖版约 60 秒 | 竖版要重新写，不是横版的缩短版 |
| 旁白要什么腔调：克制的纪录片腔，还是铿锵有力、调动情绪的广告宣传片腔 | 宣传片腔 | 选音色完全不同。本项目第一次按纪录片腔做，被评价"不够激情" |
| 授权范围：委托方对哪些素材有二次使用权 | 只有委托方官方账号发布的素材 | 决定能从哪里取画面 |
| 委托方能不能提供原始录像 | 不能，自己上网找 | 决定素材检索的工作量 |
| TTS 用哪个平台 | 阿里云百炼 | 有的委托方只允许指定平台 |
| 发布在哪个平台 | 抖音 / B 站 / 视频号 | 决定响度、码率和竖版字幕大小 |
| 人物能不能用 AI 生成或代码绘制 | 不能，人物只用真实影像 | 本项目试过代码小人、3D 和 AI 人物，都被否定 |

## 查证

- 用网络搜索逐条核对：年份、城市、对阵、人名、数字、引语。每条记下出处链接。
- 查不到出处的说法直接删掉，不要用"据说"去圆。
- 容易出错的地方：
  - 首次到访与首次正式比赛不是一回事。本项目里，1979 年是表演赛，2004 年才是第一场正式比赛。
  - 间隔天数要自己算（例如 2019-10-10 到 2025-10-10 是 2190 天）。
  - 引语要找原话出处，不要用转述。
- 把核查结果写成一张表，交付时附在最终报告里。

## 分幕结构（经过验证的节奏）

```
冷开场钩子（一个反常识或有画面感的事实，5–15 秒）
→ 起源（最早的那次）
→ 第一次高潮（一个标志性瞬间，用真实影像）
→ 扩张蒙太奇（逐年翻页或快切，按拍点）
→ 低谷（音乐硬停，近乎静默，只剩一个声音元素）
→ 回归爆发（音乐重新进入，最强的画面）
→ 当下阵容快切
→ 片尾标版（标题、日期、署名）
```

- 结尾能燃起来，靠的是爆发前那几秒的安静。静默段至少留 15 秒。
- 每句旁白控制在 15 个字以内。长句拆开，靠停顿制造节奏。

## 镜头表

写脚本时同步写镜头表，每一句都标清画面由谁来呈现：

| 列 | 内容 |
| --- | --- |
| 句号 | L01、L02…（竖版用 V01…） |
| 旁白 | 字幕原文 |
| 画面 | 真人（写明素材和时间段）/ 代码（写明是什么组件）/ AI（写明提示词要点） |
| 音乐位置 | 落在哪个拍点或事件上 |
| 来源 | 事实出处链接 |

分工：

- **真人影像**：所有人物和动作。找不到就换说法，或者改用代码呈现数据，不要用 AI 补人物。
- **代码**：数据、文字、地图、标尺、计分牌、翻页、票根、转场、片头片尾包装。
- **AI 生图**：只补没有影像的环境画面，例如老街景、空房间、静物、远景背影，不能出现可辨认的人脸。

## 竖版要重写

- 第 1 秒必须有钩子：大字、反常识的事实，配一记重击音效。
- 字幕更大（58 px，每行不超过 14 个字），旁白更短更密。
- 结构可以压缩成：钩子 → 起源 → 高潮 → 蒙太奇 → 硬停 → 爆发 → 标版。

## 先做样片

正式铺全片前，先做 10–20 秒样片，包含真人片段、代码包装、字幕和混音，确认风格后再继续。本项目在样片阶段换了三次方向：
- 纯代码动画，被评价"呆"；
- 3D 小人，被评价"假"；
- 最后定为真人影像加代码包装，用户认可。
