# 踩坑清单、质检、收尾清理

## 踩坑清单

| 现象 | 原因或解决 |
| --- | --- |
| Chrome 起不来、venhance 报错、下载报 SSL 错误 | 有沙箱的 agent 里，这些都要在沙箱外运行，或申请完整的网络和系统权限 |
| YouTube 下载报 SSL error 35 | 网络不通。中国大陆需要代理 |
| TikHub 给的 YouTube 直链下载 403 | 直链绑定了 TikHub 服务器的 IP。改用 yt-dlp |
| yt-dlp 报 403 | 加 `--extractor-args "youtube:player_client=web_safari,android"` |
| B 站下载只有 11 KB/s | akamai 镜像对单连接限速。换镜像，用 Range 分段并行下载 |
| 导入某个工具模块后，莫名执行了它的命令 | 被导入的模块没写 `if __name__ == "__main__":` 保护 |
| 管道里看不到进度输出 | 用 `python -u`，并配合 `grep --line-buffered` |
| zsh 里 `rm out/*.mp4` 报 "no matches found"，脚本直接退出 | 脚本统一用 bash 写，并加 `shopt -s nullglob` |
| zsh 里 `for x in "a b"; set -- $x` 没有按空格拆开 | zsh 默认不分词。改用 `for a b in v1 v2 v3 v4`，或者换成 bash |
| montage 内存报错 | 单格宽度不要超过 480 |
| 看图工具显示的还是旧图 | 换一个新文件名重新生成 |
| 竖版字幕只有底板、没有文字 | 文字画到了离屏画布上，用 `onV()` 包一层 |
| 白字压在白球衣上看不清 | 名字条下面加底部渐变（透明到 0.7 黑） |
| 片段里混进转场或甩镜头 | 抽首、中、尾三帧检查。缩短入出点，再用 rife 慢放补足时长 |
| 烧录字幕被裁掉一半 | 先测白字所在的行，再调整裁切框，要么整段保留，要么完全裁掉 |
| 旁白句子互相重叠 | timeline 里加断言。改成可变拍数的蒙太奇页，或者插入过渡场景 |
| 人声和背景音此起彼伏 | 去掉闪避和 loudnorm，改用固定 EQ 凹口、段落音量和固定增益 |
| 交付文件峰值超过 0 dBFS | 过采样到 192 kHz 再限幅，`limit=0.75` |
| 母版码率 80 Mbps 以上 | 颗粒导致的，正常。交付用 crf 19 加 maxrate |
| 接触表的时间标签对不上 | 按"行号 × 列数 × 步长"自己换算，再抽单帧确认 |
| 国内服务器下载反而更慢 | 先测速。实测开代理的本机 B 站 6.6 MB/s，国内服务器只有 1.3 MB/s |
| 局部改动后要重渲 | `rerender_part.sh` 只重渲包含改动的那一段，然后重新拼接 |

## 质检清单（交付前逐条确认）

- [ ] 每个场景至少看过 2 张静帧，没有空帧、缺图、文字溢出。
- [ ] 成片用接触表从头扫到尾，2.5 秒一格。
- [ ] 重音、硬停、爆点这几帧单独抽出来核对过，画面正好落在事件时间上。
- [ ] 帧数等于 duration × 30，音频和视频时长一致。
- [ ] timeline 的旁白重叠断言通过。每句旁白在人声频段比背景高 +1 dB 以上，字幕和旁白对得上。
- [ ] 旁白每句都经过语音识别核对，没有念错的字。
- [ ] 交付文件约 -16 LUFS，峰值不超过 -1.5 dBFS。
- [ ] 片尾有配乐署名。CREDITS.md 里每条素材都写了账号和视频 ID。
- [ ] 人名、年份、比分、城市、引语都核对过出处。
- [ ] 画面里没有 AI 生成的人脸，旁白没有克隆真人声音。

## 最终报告要写的内容

- 交付文件的路径、分辨率、时长、码率、响度。
- 没找到的素材，用什么替代了，替代方案是谁定的。
- 因为查不到出处而删掉的说法。
- 配乐署名要求。
- 哪些地方需要用户亲自确认：曲目、音色、整片观感。说明你看过和没看过的部分，例如"抽帧看过，没有完整看一遍、听一遍"。

## 收尾清理（用户说告一段落时）

可以删除（都能用脚本重新生成）：
- `out/` 里除交付文件、最终混音 wav 和试听文件之外的所有内容：分段渲染文件、母版、静帧、接触表、样片、试音、临时目录。
- 没用上的下载素材。删之前先把账号和视频 ID 记进 CREDITS.md。
- 第三方参考素材，以及抠像、分割用的模型权重（可以重新下载）。
- `__pycache__`、`.numba_cache`。

保留：
- 交付文件、`assets/CREDITS.md`、所有脚本、时间轴、台词表、旁白 wav（含多版本）。
- 成片用到的素材、配乐、AI 图。
- `scenes/clips/`，这样不用重跑预处理就能直接重渲，重渲母版大约 15 分钟。
- `.venv` 和 `node_modules` 是运行环境，不算中间文件。只有用户明确要求时才删。

删除时用明确的路径列表，不要写 `cd 某目录 && rm -rf *` 这种形式。删完报告释放了多少空间、保留了什么、以后怎么重新生成。
