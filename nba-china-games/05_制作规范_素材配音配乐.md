# 制作规范：素材、配音、配乐

> 更新：人物画面改用 NBA 官方真实影像并做二次加工，见 `06_v3_混合呈现方案.md`。下面第一节中「人物不写实」「官方内容只作参考、不直接出现」两条已作废，其余仍然有效。

## 一、素材来源规则

贵方的授权只能覆盖 NBA 自己拥有版权的内容。Getty、路透社、新华社、央视、《华盛顿邮报》等第三方的照片和视频，版权在对方手里，NBA 的授权覆盖不到，所以这类素材一律不下载、不使用。

素材按以下优先级取用：

| 优先级 | 来源 | 用法 | 记录要求 |
| --- | --- | --- | --- |
| 1 | **代码绘制** | 默认方式：人物线稿、球场、地图、计分牌、光点、文字动画 | 无 |
| 2 | 公有领域 / CC0 / CC BY 资源 | 地图数据（Natural Earth）、开源字体（思源宋体、思源黑体，OFL 授权）、CC BY 配乐 | 在 `production/assets/CREDITS.md` 中逐条登记出处和授权，片尾或简介里署名 |
| 3 | NBA 官方渠道发布的内容（NBA.com、NBA 官方 YouTube / 微博） | 只作为线稿化的动作参考，不直接出现在画面里 | 登记链接，由贵方确认属于 NBA 自有版权 |

人物不写实：球员一律用代码绘制的线稿形象，靠号码、身高标尺和名字来识别，不描摹任何第三方照片。

## 二、配音：阿里云百炼

- 待测模型：
  - `qwen3-tts-instruct-flash`：可以用自然语言描述语气，例如「低沉、克制的纪录片旁白，语速稍慢，句尾下沉」。
  - `cosyvoice-v3-plus` / `cosyvoice-v3-flash`：支持情感指令，还能返回逐字时间戳，可以让字幕和画面逐字对齐。
- 测试方法：挑 3 句代表性旁白（平静叙述、悬念、结尾低语），每个模型挑 2 到 3 个男声音色各合成一遍，交给贵方试听后选定。
- 生产方法：逐句合成，每句出 3 版，挑最好的一版；量出真实时长后写进时间轴；混音时按场景加混响，旁白出现时音乐自动压低。
- API Key 存放：写在 `production/.env`，内容为一行 `DASHSCOPE_API_KEY=你的key`。这个文件已加入 `.gitignore`，不会被提交。不要把 Key 直接贴在对话里。

## 三、配乐：成品曲目 + 代码音效，按节拍对齐画面

1. **主旋律用 CC BY 4.0 成品曲目**，商用免费，只需署名。候选是同一位作曲家 Sascha Ende 的作品，音色风格统一：
   - 《Cinematic Trailer 001》（1 分 39 秒，管弦乐加合唱，从紧张铺垫推到高潮）：用于第一幕和第二幕。
   - 《The Awakening [trailer intro]》（1 分 38 秒，快节奏，冲击感强）：用于第四幕重逢。
   - 《Dubstep Trailer 1》（2 分 08 秒，电子重低音）：作为偏年轻化的备选，适合竖版短视频。
2. **第三幕的静默和钢琴**用代码合成。
3. **秒级对应的做法**：先把曲子的节拍、小节和能量曲线测出来，只在小节线上剪接；然后**让画面时间轴去适配音乐**。画面是代码，每个镜头的时长可以精确到帧。扣篮、闪白、翻牌落定这些关键点，再叠加代码合成的冲击声、上升音和球的弹跳声，和画面共用同一份时间轴文件。
4. **限制说明**：我能分析音乐的节拍和能量，但听不出好不好听。曲子需要贵方试听确认。完整音质版需要在曲目页面点击下载，目前只拿到了低码率预览版。
5. 百炼的 Fun-Music 音乐生成目前是邀测状态，而且生成结果的段落结构不可控，不作为主方案。

## 四、样片 v1 已验证的内容

- 渲染管线：HTML/Canvas 的每一帧都由时间 t 决定，无头 Chrome 逐帧截图，ffmpeg 编码。11 秒、330 帧、1080p，渲染约 60 秒。
- 音画同步：样片中扣篮冲击声检测在 7.505 秒，闪白最亮帧在 7.500 秒（第 225 帧），鼓点全部落在 0.5 秒间隔的节拍上。
