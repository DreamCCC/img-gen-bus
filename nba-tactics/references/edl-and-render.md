# EDL 与渲染

`tools/render_play.py` 读一张 EDL（JSON），同一条时间轴驱动取帧、调色、图层、字幕和混音。完整示例见 `kd_macau/e464_edl.json` 和 `kd_macau/e453_edl.json`，新片照着改。

## 顶层字段

```json
{
 "work": "work/e453", "fps": 30, "size": [1920, 1080],
 "orig": "work/e453/fr/orig",
 "slow": {"dir": "work/e453/fr/slow", "from": 95, "mul": 4},
 "audio_src": "raw/e453_pullup.mp4",
 "vo": {"lines": "e453_vo.json", "dir": "audio/e453"},
 "out": "out/e453_v1.mp4",
 "style": {"KD": "gold", "SG": "orange", "VV": "white", "TB": "blue"},
 "anchors": {"rim": [229, 802, 236]},
 "ball": [[142, 1328, 553], [145, 1441, 572]],
 "segments": [...], "layers": [...]
}
```

- `style` 给每个球员定角色色：`gold` 是主角（得分人），`orange` 是第二主角（助攻人），`blue` 是防守人，`white` 是其他进攻球员。主角和第二主角的名牌优先级最高，身体不会被别的名牌压住。
- 所有路径都相对于 EDL 所在目录。

## 时间写法

- 段或旁白 id 加偏移秒：`"L3+0.5"`、`"C"`、`"C.end-0.2"`、`"s2+1.6"`。
- `from`、`to`、`at`、`src_on` 是**原片帧号**（30fps），不是输出时间。

## 段（segments）

| kind | 字段 | 说明 |
| --- | --- | --- |
| `play` | `from, to, speed` | `speed<1` 时从 `slow` 目录取插帧；`speed=1` 时加 `audio_db` 会垫原声（如 `-9`，进球后用 `0`） |
| `rewind` | `from, to, dur` | 倒带，带扫描线和色偏 |
| `freeze` | `at, stop, spot, focus, glow?` | 时停。`spot` 里的人保持彩色，其他人变灰；`focus` 是开场波纹的中心。`glow: true` 时背景再虚化，`spot` 里的人上浮几像素、描一圈本队颜色的光（特效版用），这些人的蒙版自动换成 SAM2 精细蒙版；没有跟踪框的人在顶层 `mask_box: {"帧号": {"key": [x1, y1, x2, y2]}}` 里给框 |
| `card` | `at, score, rows, credit` | 收尾卡片：背景虚化缓推，比分、三行数据、来源 |

通用字段：

- `vo: [["L3", 0.35]]`：旁白在段开始后第几秒进。写成 `{"end": 1.45}` 表示旁白在段开始后 1.45 秒**结束**，用来把"命中"压在球进框那一帧。
- `pad`：时停在最后一句旁白结束后再停多久；`dur` 是定死的时长；`min` 是最短时长。
- `badge`：左上角角标，如"时停""慢放 ×0.25""子弹时间 ×0.25""出手""倒回"。
- `sfx`：`stop`、`resume`、`rewind`。
- `zoom: [段末倍率, 焦点]`：虚拟推镜。焦点可以是球员 key、像素坐标 `[x, y]` 或 `null`（沿用上一段）。时停一般用 1.05–1.16，下一段回到 1.0。

时停时长不用手算：渲染器按旁白时长加 `pad` 自动排，句与句之间至少隔 0.15 秒。

## 图层（layers）

通用字段：`on`、`off` 控制显隐，前后各有 0.2 秒淡入淡出。`img_off` 表示到这个时间就不在画面上画了，但战术板上还保留。`id` 用于收尾大战术板的 `show` 列表。`anim: [起, 止]` 控制生长动画。

**地板图层**（在球场坐标里画，随镜头移动，会被球员身体挡住；同一套代码也画在小战术板上）：

| type | 字段 | 用途 |
| --- | --- | --- |
| `ring` | `keys, r?, pulse?` | 脚下圆圈；`pulse` 是向外扩散的脉冲圈 |
| `path` | `key, from, to, color, label?` | 跑位轨迹，带箭头随时间生长；`label` 如"突破""协防""扑防" |
| `pass` | `a: [key, 帧], b: [key, 帧], color, bend?, flow?` | 传球弧线，地面投影。`flow: true` 加光晕、画线时的领头光点、画完后沿线循环的流光 |
| `hull` | `keys, label` | 收缩防守的包络区域，如"三人收缩" |
| `tether` | `a, b` | 两人之间的测距虚线，自动标"x.x 米" |
| `radius` | `key, defs, anim` | 以 key 为圆心、半径到 `defs` 里最近那个人的范围圈，标"最近防守人 x.x 米" |
| `shotline` | `key, label` | 高亮三分线，出手点到篮筐的投篮线，标出手距离 |
| `space` | `gold, label?, anim` | 空间控制图：每块地板归离它最近的球员，按队着色，`gold` 球员那块金色加金边；`anim` 期间从他向外铺开。只画在画面上，不上小战术板 |
| `cone` | `key, to, len?, half?, label?, anim` | 防守视线锥：从 `key` 指向 `to` 的扇形（默认 14 英尺、半角 24°），越远越淡 |
| `wave` | `key, color, on, off` | 接球冲击波：`on` 时刻起两圈地板波纹扩散，`off - on` 是时长；同时响 `wave` 音效。接球时刻 = 段开始 + (接球帧 - 段起帧) / speed / 30 |

绘制顺序（从下到上）：space、hull 和 radius 和 shotline、cone、path、pass、tether、wave、ring；地板层合成之后画 ghost，再画 goal。特效代码在 `tools/fx.py`。

**画面图层**：

| type | 字段 | 用途 |
| --- | --- | --- |
| `tag` | `keys` | 名牌 `#号码 名字`，带避让 |
| `note` | `key, text, color` | 头顶弹字，如"空位" |
| `ball` | `from, to` | 按顶层 `ball` 的点画带光晕的球和拖尾 |
| `arc` | `at, key, anim` | 出手弧线，从出手点画到 `anchors.rim` |
| `pop` | `text, src_on, fx?` | 篮下弹出"+2""+3"，`src_on` 是球进框的原片帧，同时响音效。`fx: true` 换成带光晕、回弹的大号字 |
| `goal` | `src_on, on, off` | 进球特效：篮筐爆闪、两圈光环、火花、画面轻震，响 `boom` 音效。和 `pop` 一起用 |
| `ghost` | `key, from, to, step?, n?, prompt?` | 突破残影：从 `from` 到 `to` 每 `step` 帧（默认 4）取一张球员轮廓，当前帧往前最多 `n` 张（默认 6），按镜头运动对齐到当前画面，染成本队强调色，越旧越淡，不盖住球员本人；时停时留在原地成一串拖影 |
| `title` | `lines` (3 行) | 左上角比赛信息卡：赛事、节次时间和比分、这球是什么 |
| `board` | `pos?, s?, show?` | 小战术板。默认在右上角，和画面同步；`pos: "card"` 是收尾卡片上的大板，`s` 是球员点停在的帧，`show` 列出要画满的路径和传球 id |

`src_on` 换算成成片时刻时，取 `on` 之后第一次出现这一帧的播放段：开头原速段和后面慢放段都含进球帧，特效和音效要落在慢放那次。

残影轮廓由 SAM2 抠，存 `work/<球>/masks_ghost/`，渲染前自动补齐。有跟踪框用跟踪框，人工补点的帧用脚底点和身高推框。两人重叠时 SAM 常抠错人，渲染前先把这批轮廓拼图看一遍；抠错的帧在 `prompt` 里写 `{"帧号": {"box": [...], "pos": [[x, y], ...], "neg": [[x, y], ...]}}`（正点点在本人球衣和脚上，负点点在挡着的人头上），删掉那几张 npz 重跑。e453 的 188、192 帧就是这样修的。

`space` 的标签放在金色格子落在画面内那部分的重心：格子常延伸到画外，用整格重心的话标签会被推到很远，压到球员身上。

## 名牌和标签的避让规则（已写进渲染器）

1. 按优先级落位：主角、第二主角，然后是收缩区标签，再是其他名牌，最后是距离标签。
2. 当前这句字幕的区域先放进已占用列表，标签不会压字幕。
3. 和已经放好的标签重叠时往上推；推开超过 10 像素，就画一根引线指回球员。
4. 不压主角和第二主角的身体：横向让到离自己锚点近的那一侧。
5. 不压战术板和信息卡：挪到上下左右里位移最小、又不出画的一侧。
6. 战术板上的姓名依次试右、左、上、下四个位置，选第一个不压别的圆点的。

还是挤不开时，改 EDL：缩短那几个名牌的显示时间，或者用一个 `hull` 标签代替三个防守人的名牌。

## 渲染与自检

```bash
python tools/render_play.py e453_edl.json --preview 0              # 只打印时间轴（各段和各句旁白的起止），很快
python tools/render_play.py e453_edl.json --sheet 1.0              # 每秒一格联系表，看节奏
python tools/render_play.py e453_edl.json --preview 420,770,950    # 指定输出帧的全尺寸图 → work/eNNN/preview/
python tools/render_play.py e453_edl.json --out out/e453_v1.mp4    # 全片，8 进程，1540 帧约 3 分钟
```

联系表和全片用了多进程，要在沙箱外运行。

### 先跑两个检查脚本

```bash
python tools/check_shot.py e453_edl.json      # 不到 1 秒
python tools/check_labels.py e453_edl.json    # 只算布局不出画面，1500 帧约 1 分钟；有错误时退出码为 1
```

`check_shot.py` 拿画面追踪结果和 PBP 对账：
- 投篮人起跳帧（`players` 配置里 `air` 段的起点）离篮筐的距离，和 `shot_distance` 比。差 1 英尺以内算通过，1–2 英尺提醒，超过 2 英尺报错。超过 2 英尺多半是标定、认人或脚底点错了，回到视觉管线查。
- 起跳点在三分线内还是线外，和 2pt/3pt 对不对得上。
- 投篮线标签、+2/+3、卡片上的"本场第 N 分""第 N 次助攻"、卡片比分、信息卡上的出手前比分、旁白里的"N 英尺"。

`check_labels.py` 逐帧量名牌、距离标签的最终位置：
- **错误**：名牌互相重叠、压住字幕、压住战术板、角标或信息卡。
- **提醒**：压住主角或第二主角的身体，或者引线超过 220 像素。

同一个问题在相邻帧连续出现时，合并成一段报告，并给出最严重的那一帧，直接拿去 `--preview`。报告存到 `work/eNNN/qa/labels.json`。

两个脚本都是 0 错误后，再看图。脚本**查不了**这些：线贴不贴地板、蒙版有没有抠错人、圆圈套没套住脚、画面好不好看。

### 再看全尺寸图

**每一段至少挑一帧全尺寸图看。** 联系表缩略图看不出这些细节。逐项看：

- [ ] 名牌不重叠，不压主角身体，不压字幕；引线指向正确的人。
- [ ] 脚下圆圈套住脚（不是套住影子或旁边的人）；跑位线起点在人脚下。
- [ ] 线被身体挡住，看起来像画在地板上；测距线没有让人误以为连着另一个人。
- [ ] 时停时，只有 `spot` 里的人是彩色的，没有抠错人（补蒙版脚底偏差大时要特别看）。
- [ ] 小战术板的点位和画面一致；收尾大板的路径完整，姓名没被挡住。
- [ ] "命中"字幕和 +2、+3 落在球进框那一帧。
- [ ] 卡片上的数字和 PBP 一致。
