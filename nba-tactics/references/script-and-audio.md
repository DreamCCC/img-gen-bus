# 旁白、混音与合成成片

## 写旁白

- 口语化，像懂球的朋友在讲，不用"弱侧轮转""Drop""ICE"这类术语。必须用时换成大白话："马绍尔离开杜兰特，退到中间协防"。
- 第一句给结论和悬念，第二句固定是"这球是怎么打出来的？倒回去看。"，最后一句点出规律（"补防只要扑过头，他就有这一步"）。
- 每次时停一句，只讲画面上此刻能看到的一件事：谁持球、谁离开了谁、拉开多远。数字要和画面上的标签一致。
- 子弹时间的旁白要短（"申京马上分球。"），否则慢放段不够长。
- 句首不要孤零零放一个音译人名，TTS 容易读错。给名字加点上下文，如"补防的里萨谢扑过来"。
- 距离用"米"（观众更有感觉），出手距离沿用 PBP 的"英尺"。
- 每球 9–11 句，总共 30–35 秒旁白。

## 台词文件 `eNNN_vo.json`

```json
[
 {"id": "L1", "mood": "hype", "text": "第三节，火箭领先10分。……", "say": "第三节，火箭领先十分。……"},
 {"id": "L3", "text": "……盯杜兰特的，是3号马绍尔。", "say": "……是三号马绍尔。",
  "alias": {"神经": "申京", "马歇尔": "马绍尔"}},
 {"id": "L8c", "mood": "hype", "text": "12英尺，命中！", "say": "十二英尺，命中！", "pick": 3}
]
```

- `text` 是字幕（阿拉伯数字），`say` 是给 TTS 念的（中文数字）。不写 `say` 就念 `text`。
- `mood: "hype"` 时，从 3 条里挑更亮、动态更大的那条；默认挑时长居中的。
- `alias`：ASR 对人名的同音误识写成"误识 → 正字"，**只用于核对，不改念法**。常见的有：申京→神经/申经，马绍尔→马歇尔/马少尔，比贝罗维奇→比贝洛维奇。
- `pick`：人工指定第几条 take。自动核对会去掉标点再比对，停顿位置错了（"已经晚了二十五英尺"）查不出来，要看识别结果的断句，或者请用户听。
- 改了 `text` 或 `say` 之后，要换一个新 id（或者删掉 `takes/` 里这一句的缓存），不然会复用旧音频。

## 合成与核对

```bash
python tools/vo.py e453_vo.json audio/e453 3
```

用百炼 CosyVoice `longfei_v3`（`cosyvoice-v3-flash`），1.25 倍速，每句 3 条 take。用 `qwen3-asr-flash` 识别后和台词比对，去掉首尾静音。输出 `LN.wav`、`durations.json`、`picks.json`。

- 如果三条都识别成同一种说法（"这一球"都念成"这球"），说明 TTS 就是这么读的，直接把字幕改成实际读法。
- 某句三条都核对不过时，先看是不是 ASR 同音误识（加 `alias`）；是真念错了（"往里突"念成"往里吐"），就改写台词。
- 少见的音译名，ASR 本身也不稳定。挑读音最接近的那条，并在报告里请用户留意这个名字。

## 混音（渲染器自动完成，不做闪避）

| 声音 | 电平 | 说明 |
| --- | --- | --- |
| 旁白 | 约 -22 dBFS | 0 dB 叠加 |
| 原速段原声 | 段上写 `audio_db: -9`，约比旁白低 16 dB | 原声是英文解说，只垫底，听得出现场感就行 |
| 进球后没有旁白的空档 | `audio_db: 0` | 观众欢呼用原始音量 |
| 时停、继续、倒带音效 | -6 dB | `sfx` 字段 |
| 时停底噪 | -30 dB | 低频和弦，避免时停时完全没声音 |
| +2 / +3 | -4 dB | 低频"咚" |

最后整体归一到峰值 -1 dBFS。单球成片约 -21 LUFS。默认不加背景音乐；用户要加时，按根经验库的规则：不闪避，用固定 EQ 凹口和固定增益。

测响度：

```bash
ffmpeg -hide_banner -i out/e453_v1.mp4 -af ebur128=peak=true -f null - 2>&1 | grep -A12 Summary
```

## 多球合成成片

1. 按比赛时间顺序排列（时钟大的在前）。每球自带开场信息卡和收尾卡片，不需要另做总片头。
2. 先确认各段规格一致（分辨率、帧率、采样率），并看下一球第一句旁白从第几秒开始（`--preview 0` 会打印）。
3. 画面做 0.5 秒交叉淡化（`xfade`）。**音频不做交叉淡化**：下一球的旁白通常在 0.4 秒就开始，交叉淡化会把第一个字压低。改成上一球尾部淡出，下一球从起点开始就是满音量叠进来。

```bash
ffmpeg -y -i out/e453_v1.mp4 -i out/e464_v1.mp4 -filter_complex \
 "[0:v][1:v]xfade=transition=fade:duration=0.5:offset=<第一段时长-0.5>,format=yuv420p[v];\
  [0:a]afade=t=out:st=<第一段时长-0.5>:d=0.5[a0];[1:a]adelay=<偏移毫秒>:all=1[a1];\
  [a0][a1]amix=inputs=2:normalize=0:duration=longest[a]" \
 -map "[v]" -map "[a]" -c:v libx264 -crf 18 -preset medium -pix_fmt yuv420p \
 -c:a aac -b:a 192k -ac 2 -movflags +faststart out/成片.mp4
```

4. 复查：全片每 4 秒一格的接触表，转场前后 1 秒每 0.2 秒一格的转场条，再测一次响度。
