本仓库各子项目实际踩过的坑。宣传片流程的坑（YouTube SSL、TikHub 403、B 站限速、montage 内存、白底白字、闪避等）另见 `nba-china-games/hybrid-promo-video/references/troubleshooting-and-qa.md`，这里不重复。

## 1. 沙箱和环境

| 现象 | 原因 | 修法 |
| --- | --- | --- |
| `xargs: sysconf(_SC_ARG_MAX) failed` | 沙箱禁止这个系统调用 | 改用 bash 循环加 `&` 和 `wait` 并行 |
| `ps`、`kill`、`pip install` 报权限错误 | 沙箱限制 | 这几类命令申请 `all` 权限运行 |
| 下载卡住或 SSL 报错 | 域名不在白名单 | 申请 `full_network`；CDN 域名也要放行 |
| `pkill -f "xxx(1)"` 杀不掉进程 | `-f` 的参数是正则，括号是元字符 | 先 `pgrep -fl` 查到 PID，再 `kill PID` |
| 同一任务跑了两份，互相覆盖输出 | 重试时没确认旧进程已退出 | 启动前 `pgrep -fl 脚本名`；重复的杀掉旧的 |
| zsh 下脚本在通配符处退出 | 没有匹配时 zsh 报 `no matches found` | 用 `setopt nullglob`，或改用 bash 运行 |
| `echo ====` 报 `= not found` | zsh 会把 `=` 开头的词展开成命令路径 | 分隔符用引号括起来，或改用 `----` |
| 后台 Python 一直没有输出 | 输出被缓冲 | 加 `python -u` |
| 多进程脚本反复自我启动 | 少了 `if __name__ == "__main__":` | 补上 |
| 大文件一次性读入超时或内存爆 | 一次性 `read()` | 流式读写；抽帧用 ffmpeg 管道 |
| `ProcessPoolExecutor` 报信号量权限错误 | 沙箱禁止多进程信号量 | 申请 `all` 权限运行（`render_play.py` 全片和联系表） |
| `tech-api.nbadata.cn/dev/sql` 返回 nginx 403，换请求头也一样 | 网关按 IP 白名单拦截，本机（VPN 出口）不在名单里 | SSH 到 `root@8.152.222.232` 代发，用 `nba-tactics/tools/nba_sql.py`；下载接口 `videoPlay` 不限 IP |

## 2. 下载素材

| 现象 | 原因 | 修法 |
| --- | --- | --- |
| yt-dlp 403 | 默认的 player client 被风控 | `--extractor-args "youtube:player_client=..."` 换客户端，见宣传片踩坑清单 |
| TikHub 翻到第 10 页左右开始报错 | 接口分页不稳定 | 每页加重试和退避；结果落盘，可续传 |
| 同一素材下了两遍 | 没有按 id 去重 | 先查本地 `raw/` 是否已有 |
| 素材 4:3 带黑边，或两侧有文字横幅、台标 | 原片如此 | `cropdetect` 加接触表人工确认，在 picks 里写裁切比例 |
| 素材里文字卡、水印太多 | 预告片和电视录像常见 | 换素材；九宫格里的小格尤其不能用 |

## 3. 生成接口

### 百炼和万相

| 现象 | 原因 | 修法 |
| --- | --- | --- |
| 对口型视频看着卡 | wan2.7-i2v 部分片段每 5 帧有 2 帧重复（标称 30 fps，实际约 18 fps） | `img-gen-bus-skills/scripts/smooth_dups.py`；每条生成后都跑 `video_qa.py` |
| 音频驱动的参数不生效 | 只有 wan2.7-i2v 支持 `driving_audio`；wan3.0-video 不支持 | 有音频的镜头用 wan2.7-i2v，其余用 wan3.0-video |
| 本地音频文件传上去报错 | 要先上传到临时 OSS 地址 | `OssUtils.upload` 后，请求头加 `X-DashScope-OssResourceResolve: enable`，见 `creator-channel/tools/wan_video.py` |
| 多张角色图画风不一致 | 每张都是文生图 | 用 qwen-image-3.0-pro 的图像编辑，以定妆照做参考图，见 `music_remix/baby_citypop/mina/edit.py` |
| 代码画或 AI 生成的人物"呆、怪异" | 动作和表情不自然 | 真实人物一律用真实影像；虚拟角色用万相生成视频，不在代码里画人 |

### Suno

| 现象 | 原因 | 修法 |
| --- | --- | --- |
| 网页里播放不了（`[SW Mango] Failed to fetch`、m3u8 失败） | Suno 自己的 Service Worker 出问题 | 直接下载文件；或在开发者工具里绕过 Service Worker |
| 上传原曲被拒 | 版权检测 | 用 `melody_guide.py` 合成只有旋律和和弦的引导音轨再上传 |
| 风格描述里的歌手名不起作用 | 歌手名被过滤 | 用年代、乐器、制作手法描述风格 |
| 结果不像翻唱 | 用了 Extend | 用 Cover 模式 |
| 风格框里是自动填的描述 | 上传后会自动生成 | 替换成自己的风格描述 |
| 桥段被引导旋律限制住 | 桥段也给了旋律 | 桥段不给旋律，让 Suno 自己写 |
| 速度漂移 | 生成音乐本身如此 | 实测拍点，时间轴吸附到拍点上 |

参数参考：Audio Influence 80%，Style Influence 75%，Weirdness 35%。喜欢的版本可以存成 Persona 复用。自定义 Voice 需要本人验证过的声音。

## 4. 渲染和视频

| 现象 | 原因 | 修法 |
| --- | --- | --- |
| 九宫格某格在中途跳到文字卡 | 片段比镜头短，播完后读到了预告片的字幕卡 | 小格片段设 `loop`（如 3 秒），帧号回绕时重开读取器 |
| 九宫格里没轮到的格子是空的纯色块 | 只渲了已揭示的格子 | 没揭示的格子放电视雪花和频道号，不能留空 |
| 某几秒画面又暗又糊 | 素材本身有运动模糊或太暗 | 素材池里排除这几段（`BLURRY` 名单） |
| 独奏段画面停滞、空洞 | 没有对应的画面 | 按分轨能量找出独奏区间，用万相生成演奏镜头 |
| 播放卡顿，但逐帧看正常 | 码率峰值超过 100 Mbps（颗粒和噪点导致） | `-crf 18 -maxrate 40M -bufsize 80M` |
| 渲染太慢（每帧 1 秒以上） | scipy 高斯模糊、逐像素 numpy 运算 | 换 OpenCV；调色查找表（LUT）、暗角、扫描线遮罩加缓存；用 cProfile 定位 |
| 换了实现后颜色有细微变化 | 边界处理不同（scipy 默认 reflect） | `cv2.GaussianBlur(..., borderType=cv2.BORDER_REFLECT)`；用 A/B 像素对比验证 |
| 慢动作段被截短 | 用 `-frames:v` 限制了输出帧数 | 按时长算帧数；检查帧数是否等于时长 × 帧率 |
| 自动切镜头切错 | 镜头推拉被场景检测当成切换 | 关掉自动检测，手工给切点 |
| 片头标题和第一句歌词叠在一起 | 标题卡时长没对齐歌词表 | 标题卡放在第一句之前，或移到间奏 |
| 剪进来的素材自带转场 | 原片剪辑里就有转场 | 挑片段时避开转场；接触表里看清楚 |
| 素材自带硬字幕 | 原片烧了字幕 | 裁掉下方或换素材 |
| 同一事件下了两条片段（id 尾号 01/02） | `item_info` 的孪生条目，内容完全一样 | 比对 md5，只留一份 |
| 跟踪编号一个回合 100 多个，球员中途"换人" | 遮挡和交叉时 BoT-SORT 串号 | 不修跟踪器：按帧段人工指认编号，串号段人工补脚底点（`nba-tactics` 的 `players.json`） |
| 球员位置在某几帧突然偏到场外 | 下方数据条挡住脚，框底不是脚底；或者球员起跳了 | 被挡的帧人工补点，起跳段写进 `air` 用两端插值。不要先怀疑相机标定 |
| 自动检测篮球全是场边静物 | 全景里球太小 | 传球中的球位和篮筐人工读点（`gridsheet.py`） |
| 名牌、距离标签压住字幕或战术板 | 避让逻辑没把字幕区和面板当障碍 | 渲染器已修；用 `nba-tactics/tools/check_labels.py` 逐帧量，不靠肉眼抽查（e464 样片里有 4 秒压板，抽查时没看出来） |
| 合成后第二段的第一个字听着发虚 | 音频交叉淡化把开头的旁白压低了 | 只做画面交叉淡化；音频是上一段尾部淡出，下一段满音量叠入 |

## 5. 3D 和模拟

| 现象 | 原因 | 修法 |
| --- | --- | --- |
| 体积光锥在镜头进入时整屏变白 | 相机在锥体内部，看到的是加法混合的背面 | 只渲正面（FrontSide）；按相机距离用 smoothstep 淡出。定位方法：逐个关掉光源和光锥渲同一帧 |
| 骨骼旋转错乱（四元数长度 0.707） | CMU 骨架里 Neck 和 Spine1 位置重合，"向上"方向是零向量，矩阵行列式为 0 | 改用 Neck1 − Spine1 作为向上方向；所有零长度骨段加保护。定位方法：打印对齐矩阵的行列式 |
| 区域着色出现彩色条带 | 区域 ID 在光栅化时被插值 | 用 flat（不插值）属性 |
| 三体模拟：说错了是哪颗球被甩出去 | 凭颜色印象下结论 | 从模拟数据里读出谁的距离发散，再写解说 |
| 引力井网格观众看不懂 | 抽象可视化没有解释 | 换成直观的表现，或配一句话解释 |

## 6. 音频、TTS、识别

| 现象 | 原因 | 修法 |
| --- | --- | --- |
| 人声出来时音乐被压低，效果差 | 用了闪避 | 不用闪避；固定 EQ 凹口加段落固定音量 |
| TTS 语气一句一变 | 每句都给了不同的情绪指令 | 统一一个基础人设，每句只改一个差异点 |
| 情绪指令不生效 | 部分音色（如 longfei）不支持逐句情绪指令 | 换音色或改用语速、停顿控制 |
| 选版本时误判念错 | 识别结果和字幕比（"4.8%" 和 "百分之四点八"） | 和实际念的文本 `say` 字段比 |
| 两句旁白重叠 | 台词比时间槽长 | 合成后检查时长；时间轴构建时用断言阻止重叠 |
| 章节卡音效进得太晚 | 按画面切换点对齐，没算声音起音 | 提前约 0.6 秒 |
| 逐字卡拉 OK 和唱的对不上 | paraformer 字级时间戳是平均分配的 | 用人声轨起音点驱动逐字擦除 |
| 真峰值超标 | 限幅器没有过采样 | 过采样限幅；`loudnorm` 复查 |
| ASR 核对把"申京"判成念错（识别成"神经"） | 音译人名的同音误识 | 台词行加 `alias`（只用于核对），见 `nba-tactics/tools/vo.py` |
| 自动核对通过，但听起来断句错了（"已经晚了二十五英尺"） | 核对时去掉了标点，停顿位置比不出来 | 拆句或改写；用 `pick` 人工指定 take，请用户试听 |

## 7. 内容和文稿

| 现象 | 原因 | 修法 |
| --- | --- | --- |
| 用户说"越到后面越不知道在说什么""戛然而止" | 大纲结构问题，不是句子问题 | 改大纲：每一段回答一个问题，结尾收回开头的悬念 |
| 文稿 AI 味重 | 讲义腔、排比、"不是而是" | 按 `口播风格指南.md` 重写，用 `ai_lint.py` 和 `style_stat.py` 机检 |
| 开头钩子不吸引人 | 用的是观众已经知道的事实 | 用反直觉的结论或具体的数字 |
| 4:3 封面把标题数字切掉了 | 从 16:9 封面直接裁 | 每个比例单独排版 |
| 播放量低 | 几百次曝光是冷启动；几千曝光、点击率低于 3% 是封面或标题的问题 | 先看曝光量再判断，对症改 |

## 8. 文件操作

| 现象 | 原因 | 修法 |
| --- | --- | --- |
| 新静帧还没渲完，旧静帧已经被删了 | 删除和重渲放在同一步 | 先渲到新目录，确认后再替换 |
| 磁盘被中间文件占满 | 万相原片、分段渲染、临时拼接都留着 | 交付后列清单删除（只删自己生成的），原始素材和用户文件先问 |
