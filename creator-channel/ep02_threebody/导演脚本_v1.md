# 《三体问题为什么无解》导演脚本 v1

口播稿：`文稿_全片v1.md`（约 3240 字）。成片约 11 分钟，16:9，1080p/30。
观众：没学过物理的普通人，看过或听说过《三体》。
一句话：用一个“一毫米改变命运”的实验开场，讲清楚“无解”到底是什么意思，再用 300 年的真实故事把它讲好看。

---

## 一、四种素材，各管什么

| 来源 | 用来做什么 | 不能用来做什么 |
| --- | --- | --- |
| **代码 3D**（three.js，`scenes/`） | 全片主体，约 65%。所有讲道理的画面：真实模拟的轨道、分屏对比、守恒量、周期解、尺度拉远、历史文档重排 | — |
| **万相 wan3.0**（`tools/wan_video.py`） | 约 20%。只要氛围、不要求物理精确的镜头：三体星球、恒纪元和乱纪元、历史场景空镜、艺术想象的外星景观 | 任何需要轨道正确的画面；任何真实人物的脸 |
| **图片生成**（qwen-image） | 给万相做首帧、尾帧，先把构图定死再让它动起来；做封面底图 | 真实人物肖像；真实文物和文件的“仿真品” |
| **全网真实影像**（TikHub 抖音检索） | 约 3%，每段不超过 3 秒。只放“真实发生过”的新闻画面：刘慈欣领雨果奖、天河二号超算 | 影视剧片段（版权风险高，乱纪元改用万相生成） |
| **公共领域图像**（维基共享资源、ESO、NASA） | 约 7%。历史人物的真实照片和画像；半人马座α 的望远镜照片 | — |

原则：**物理归代码，氛围归万相，人物归真实照片，事件归新闻画面。** 观众看到星星在动的时候，看到的一定是真实算出来的轨道。

## 二、视觉系统

### 1. 三层画面

| 层 | 长什么样 | 出现在 |
| --- | --- | --- |
| **宇宙层**（代码） | 已定稿的电影质感：发光恒星、横向镜头光晕、被星光染色的尘埃、暗色星云、暗角、胶片颗粒 | 冷开场、第二、四、五、六章 |
| **写实层**（万相） | 真实摄影质感，冷峻、壮阔；历史场景偏暖、偏旧，不出现清晰人脸 | 冷开场、第一、三、六章 |
| **档案层**（代码重排） | 深色底上的米白纸张、铜版画质感；我们自己重新排版的论文页、格言、电报；真实照片做成相片卡，带细白边和年份 | 第一、三、四章 |

### 2. 三颗星的颜色贯穿全片

红星 `#ff5a2a`、黄星 `#ffc46a`、蓝星 `#6fa8ff`。开场的三颗星，第二章的共线解和三角形解，第五章的 8 字形，都用这三种颜色，观众会一直认得“这就是那三颗星”。

### 3. 界面语言（HUD）

- 科幻界面风：1 像素细线框、角标括号、等宽数字，不用圆角大框。
- 中文标注用思源黑体 Medium；数字用等宽字体；人物原话用思源宋体，加引号。
- 标注出现时按 12 帧/秒步进描线，像仪器在锁定目标。
- 字幕始终在底部安全区，HUD 不压字幕。

### 4. 运镜规则

- 宇宙层：镜头永远在缓慢运动（环绕、推、拉），不出现完全静止的 3D 画面。
- 关键时刻用**慢动作**（模拟时间放慢到 1/4）：红星被甩出、黄星被拽回又甩走、两次模拟分开的那一刻。
- 尺度变化用**一镜到底的拉远**：第六章从 A、B 双星一路拉到比邻星，不切镜头。
- 写实层和宇宙层之间用**匹配剪辑**：万相里的三颗太阳和代码里的三颗星放在画面同一位置，溶解过去，观众感觉是“镜头飞上了天”。

## 六、声音

### 1. 总原则

- **人声是主时钟。** 先合成全片配音，拿到每个词的时间戳；音乐的剪点、重音，画面的关键帧，都挂在词上，谁也不各走各的。
- **配音**：龙三叔，1.25 倍速，按段合成、自动校对。
- **不做闪避**：音乐不会随人声自动压低又弹回来。人声和音乐靠三件事分开：选曲、固定 EQ、剪辑位置。

### 2. 音乐由两层组成

| 层 | 是什么 | 为什么 |
| --- | --- | --- |
| **流行曲层** | 观众耳熟的影视原声和名曲（歌单见下一节，版权由你处理），每章换一首 | 观众一听就进入情绪，接受度高 |
| **合成层** | 我们用代码合成的部分：低频铺底、脉冲、重音、钟表、电报机、印刷机，以及全片的“三体动机” | 时间能精确到采样点，和模拟、画面、词三者对齐 |

**三体动机**：取《查拉图斯特拉如是说》（《2001 太空漫游》）开头那三个上行的音，红星、黄星、蓝星各对应一个。观众本来就熟，又正好是三个音。这三个音在全片随剧情变化：

| 出现在 | 怎么变 |
| --- | --- |
| 冷开场，一起转圈 | 三个音轮流响，节奏整齐 |
| 队形散了 | 三个音各自跑调、节奏错开 |
| 红星被甩出 | 红星的音越来越远、越来越低，最后消失 |
| 标题卡 | 三个音同时响成和弦，加重低音 |
| 拉格朗日三角形 | 和弦干净、稳定；铅笔倒下时一个音滑走 |
| 庞加莱发现混沌 | 动机和开场完全一样地响一遍，再散开 |
| 8 字形 | 三个声部唱同一段旋律，各差三分之一个周期，正好对应三颗星在同一条 8 字上相差三分之一圈 |
| 结尾地平线 | 三个音最后响一次，渐弱 |

动机的音高会按每章曲子的调重新算，不和曲子打架。

### 4. 让人声和音乐咬合的五个做法

1. **重音找词**：每段音乐挑出最强的一两个重音，平移整首曲子，让重音正好落在关键词上。比如“混沌”“整版已销毁”“10 的 80 次方”。上一期第五章“难了十几倍”就是这样对上的。
2. **一段里有多个重音时**：先在小节线上剪接曲子（加减整小节，接口 30 毫秒交叉淡化），再把句间停顿在 ±0.3 秒内微调，让后面的词也落在拍上。句间停顿本来就是我们自己排的，听不出来。
3. **静音靠剪曲子**：要静音的地方直接把曲子剪开，留出空白，再从同一小节位置接回来，不是把音量拉下去。
4. **频率让位**：音乐固定压低 1–4 kHz 约 8 dB，这是人声最需要清楚的频段。选曲避开中高音区密集的快音型；旋律性强的乐句尽量安排在句与句之间的空档里出现（靠剪辑位置，不靠音量）。
5. **节奏不抢话**：1.25 倍速的口播很密，有人声的段落里，曲速控制在每分钟 70–100 拍，不用密集的鼓点。快节奏只放在没人说话的地方：开场模拟、标题卡、慢动作、章节转场。

### 5. 音效

风声、低频嗡鸣、甩出时的呼啸和重低音、倒带、钟表滴答、电报机、印刷机、HUD 锁定的“咔”声。代码画面里的音效直接读模拟数据：红星被甩出的那一帧就是呼啸开始的那一帧，最近距离掠过就是呼啸最响的那一帧。

三处刻意静音：第 6 镜倒回之后、第 32 镜发现错误、第 36 镜“整版已销毁”之前。

### 6. 混音验收

- 每句话在 300–4000 Hz 频段里，人声比“音乐 + 音效”高至少 12 dB。混音脚本逐句打印最差的 8 句，不达标的句子降那一段的音乐，或者换曲子的那一段。
- 把混好的成片再跑一遍语音识别，和只有人声时的识别结果对比。哪句因为音乐变差了，就改哪句。
- 成片响度 −16 LUFS，峰值不超过 −1 dBTP。
- 最后在三种设备上各听一遍：耳机、笔记本外放、手机外放。手机外放是最难的一关，低频铺底听不见没关系，但人声一定要清楚。

## 八、制作顺序

1. 你确认这份脚本和口播稿（重点看第三章和第四章的讲法）。
2. 全片配音，拿到词级时间戳，排时间轴。
3. 并行三条线：
   - 代码：先做 HUD 组件库，再按章节做 C02–C16；
   - 万相：先用图片生成定首帧，再出 13 条 480P 试样，选定后出 1080P；
   - 素材：下载公共领域照片和天文图像，从抖音找 T1、T2。
4. 粗剪：全片按时间轴拼好，配上临时音乐，给你看一版。
5. 精剪：配乐、音效、调色、字幕，出成片；同时做封面和简介。
