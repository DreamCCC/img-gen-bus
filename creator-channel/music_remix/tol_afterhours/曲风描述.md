# Thinking Out Loud × After Hours：曲风描述与上传说明

把 Ed Sheeran《Thinking Out Loud》改成 The Weeknd《After Hours》那种暗色合成器浪潮。流程同 `baby_citypop`：上传音频到 Suno 做 Cover + 风格描述。

## 文件

Suno 上传结果：原曲旋律的 guide 被判定为匹配已有录音，拒收。改走本地 remix：原唱人声分轨 + 我们的伴奏。

| 文件 | 用途 |
| --- | --- |
| `out/tol_afterhours_remix.mp3` / `.wav` | **成品**：原唱人声 + After Hours 风格立体声伴奏，−14 LUFS，峰值 −1 dBFS |
| `remix.py` | 生成成品；人声处理、电平、母带都在这里 |
| `guide.py` | 生成伴奏；改编曲就改 `arr()` 里的参数，重跑后再跑 `remix.py` |
| `out/guide_backing_stereo.wav` | 立体声伴奏，`remix.py` 用 |
| `out/guide_backing.wav` / `upload/tol_backing.mp3` | 单声道伴奏，没有旋律 |
| `upload/tol_melody_guide.mp3` | 伴奏 + 原曲主旋律（合成音色）；Suno 拒收 |
| `upload/tol_original.mp3` | 原曲 |

| `ref/after_hours_original.wav` | 风格参考，只在本地测量和对听，**不上传** |

## 一、两首歌的差距

| | Thinking Out Loud | After Hours | 改法 |
| --- | --- | --- | --- |
| 速度 | 79 BPM（节拍器录制，全曲不变） | 108 BPM | 保留 79，鼓用双倍速：底鼓每半拍一下（听感 158 BPM），军鼓在 2、4 拍 |
| 调性 | D 大调，暖 | C 小调，冷 | 转到关系小调 B 小调：D→Bm9、G→Gmaj9、A→Aadd9、Em→Em9，原旋律的音都还在新和弦里 |
| 律动 | 6/8 摇摆感的灵魂乐 | 直的四拍电子律动 | 贝斯改成十六分音符脉冲，加侧链压缩（底鼓一响、铺底往下一压再回弹） |
| 起伏 | 几乎没有，伴奏从头到尾一样响 | 长铺垫 + 一次爆发 | 见第二节 |
| 音色 | 木吉他、钢琴、真鼓 | 模拟合成器、琶音、门限混响军鼓 | 全部换掉 |

## 三、Suno 风格描述

**不要写歌手名和歌名**，Suno 会过滤。

**A 原味男声（首选）**

```text
dark 80s synthwave, retro synth-pop, 79 BPM half-time vocal over double-time four-on-the-floor drive, pulsing sixteenth-note analog bass, sidechain pumping synth pads, arpeggiated synths, gated reverb snare, B minor, cinematic night drive, melancholic and lonely, airy male falsetto, breathy, deep reverb, sparse intro, explosive drops
```

**B 中文演唱**（填中文词时用，不然 Suno 容易用英文腔唱中文）

```text
dark 80s synthwave, retro synth-pop, 79 BPM half-time vocal over double-time four-on-the-floor drive, pulsing analog bass, sidechain pumping synth pads, arpeggiated synths, gated reverb snare, B minor, night drive, melancholic, Mandarin Chinese vocals, airy male falsetto, breathy, deep reverb, sparse intro, explosive drops
```

**C 女声对照**：A 里的 `airy male falsetto` 换成 `ethereal female vocal`。

**Exclude Styles（排除风格）**

```text
acoustic guitar, piano ballad, live drums, soul, swing, folk, country, trap, lo-fi, bright happy pop
```

前四个专门排除原曲的木吉他、钢琴、真鼓和灵魂乐摇摆感，不排除的话 Suno 容易照着原曲编。

## 四、歌词框段落模板

先贴下面的骨架，再从正版歌词页把原词复制到对应标记下面。括号里的编曲要求和 guide 一致，两边对上，Suno 更容易做出起伏：

```text
[Intro: ambient synth pads, arpeggio, no drums]

[Verse 1: minimal, pulsing bass only, no drums]
（第一段主歌前半）
（第一段主歌后半）

[Pre-Chorus: drums enter, build-up, drums stop]
（预副歌）

[Chorus: beat drop, four-on-the-floor, full synths]
（副歌 So honey now 那段）
（尾句 we found love right where we are）

[Verse 2: drums stay, half pads]
（第二段主歌）

[Pre-Chorus: build-up, drums stop]
（预副歌）

[Chorus: full synths]
（副歌 + 尾句）

[Breakdown: drums out, synth arpeggio, then build-up]

[Final Chorus: biggest, layered harmonies]
（副歌 + 尾句 ×2）

[Outro: drums out, pads fade out]
```

## 五、Suno 操作和参数

1. `+ Audio` → Upload → 先传 `upload/tol_original.mp3`，选 **Cover**；提示版权受限就换 `upload/tol_melody_guide.mp3`。
2. 歌词框如果被自动填成 `[Instrumental]`，先删掉，再贴第四节的模板和歌词。
3. 参数起步值：

| 参数 | 传原曲时 | 传 guide 时 | 说明 |
| --- | --- | --- | --- |
| Audio Influence（音频影响） | 55%–65% | 75%–80% | 传原曲时压低，否则会照搬原曲的木吉他编曲；guide 本身就是目标曲风，可以调高 |
| Style Influence（风格影响） | 85% | 75% | |
| Weirdness（怪异度） | 30% | 30% | |
| Vocal Gender（人声性别） | Male | Male | C 组选 Female |

4. Song Title：`Thinking Out Loud (After Hours Ver.)`

生成后的调法：还像原曲、木吉他和摇摆感出来了，就降 Audio Influence 或升 Style Influence；旋律跑偏、认不出原曲，就升 Audio Influence。

## 六、guide 的检查结果

- 拍点对齐：guide 和原伴奏在三段副歌处做起音互相关，偏差都是 0 ms。
- 主旋律：合成旋律和原唱分轨在第一段副歌处逐帧比音高，96.6% 的帧在 1 个半音以内（八度折叠后）。
- 原曲本身：79.00 BPM，352 个拍点线性拟合残差 10 ms；D 大调（相关系数 0.95）。
