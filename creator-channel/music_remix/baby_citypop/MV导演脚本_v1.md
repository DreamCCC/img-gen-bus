## 一、一句话概念

一位 1989 年东京的虚拟偶像，带观众回到泡沫经济最闪耀的那一夜：银座霓虹、万元钞票拦出租、迪斯科扇子、苗场滑雪、平安夜酒店——最后，当年日剧里的人们和她一起唱完最后一段副歌。

基调：**纯粹的快乐和怀念**。不讲泡沫破裂，不讲后来。

## 二、视觉规则

| 项目 | 规则 |
| --- | --- |
| 色彩 | 夜：深海军蓝底 + 霓虹粉 `#FF4FA3` + 青 `#3EE6FF`；日：粉彩天空、泳池蓝、夕阳橙 |

| 画幅 | 成片 16:9；当年 4:3 的影视片段放进代码做的**显像管电视框**里，或做成九宫格的一格 |
| 字体 | 片名：细衬线片假名 + 斜体英文手写体；字幕见下方「字幕」 |
| 剪辑节奏 | 主歌 1 句 1–2 个镜头；副歌按拍切（每 2 拍或 4 拍）；"oh!" "no!" 这类呼应处做全屏闪切 |
| 三种素材的分工 | **万相**：虚拟歌手和动画场景（原创，不出现真人脸）；**影视**：当年的真实氛围，每段 1–3 秒；**代码**：数据、道具、字幕、转场、九宫格、片头片尾 |

### 调色与质感（80–90 年代日本）

调色程序：`look/grade.py`，对比图：`look/compare_v2.jpg`、`look/compare_zoom_v2.jpg`。所有素材最后都过同一套程序，干净的万相动画、代码画面和老影视片段才能看起来像同一卷录像带里的东西。

| 方案 | 模拟对象 | 特征 |
| --- | --- | --- |
| A 录像带电视 `tv89` | 1989 年电视播出、录到录像带上 | 奶油色黑位、阴影偏青、整体发糊、颜色向右渗出、亮边、扫描线、磁带噪点 |
| B 胶片电影 `film89` | 当年 35mm 富士胶片电影 | 褪色暖调、高光柔光扩散、红橙光晕、胶片颗粒、暗角 |

两套共同的规则：饱和度降低，绿色往黄青偏，霓虹粉保留；黑位不纯黑，白位不纯白。

**内容上也要对年代**：滤镜只能管质感，画面里的东西也要是那个年代的。万相和文生图的提示词统一加「1980 年代末日本」限定：方正造型的老式轿车、垫肩、大波浪或一刀切长直发、显像管电视、公用电话亭；负面词加上「现代手机、双肩包、LED 屏、现代汽车」。

**B 站压缩**：B 站转码会把细小噪点压成色块，所以噪点和颗粒做得偏大、偏柔，上传前用 B 站的码率做一遍转码测试。

### 字幕（日中双语，80 年代样式）

程序：`look/subs.py`；样张：`look/sub_telop_v2.jpg`、`look/sub_karaoke_v2.jpg`、`look/title_card_v2.jpg`

- 全片双语：日文在上（大、逐字变色），中文在下（小、不变色）；纯英文的 "Baby…" 句只出日文行
- 字幕放在 16:9 画面中间的 4:3 安全区里，当年电视字幕都在这个范围内
- 字体：日文ヒラギノ丸ゴ（最接近当年电视常用的圆黑体），中文圆体（80–90 年代港台电视字幕的味道）
- 画面先调色，字幕后叠，只加轻微柔化：当年字幕机叠上去的字本来就比画面亮、比画面清楚

| 样式 | 模仿对象 | 用在哪里 |
| --- | --- | --- |
| テロップ（电视歌词字幕） | 80 年代电视音乐节目 | 全片主力：白字粗黑边 + 投影，唱到的字变黄 |
| レーザーカラオケ（镭射卡拉 OK） | 80 年代卡拉 OK 镭射影碟 | 桥段「みんな 準備はいい?」起到最后副歌结束：白字蓝边，唱到的字变粉，日文靠左、中文靠右错开，暗示「大家一起唱」 |
| 歌名字幕卡 | 音乐节目开唱时左下角的歌名 | 前奏 I4 MINA 回头那段（11.0–14.6 秒）：♪BABY / MINA / 作詞・作曲・編曲；放在主歌会和歌词字幕重叠 |

显示规则：每句提前 0.35 秒硬切出现，下一句出现时硬切换掉（当年字幕机没有淡入淡出）；间奏和 build 段不出字幕。

逐字变色的节奏：识别器给的词时间戳是平均切的，不能用。改为在每句时间内，用人声分轨的起音强度和线性时间各占一半推进，再按每个字的音节数分配宽度（汉字约 2 拍、假名 1 拍、拗音小字并入前一拍）。

整轨程序：`look/subtrack.py`，`SubTrack().patches(t)` 给最终合成调用；直接运行生成 `out/subs_preview.mp4`（带时间码和段落名，用来核对）。

字体授权：这两款是 macOS 自带字体，用于个人发布一般没问题；如果之后要商业变现，换成开源授权的圆体（例如 Resource Han Rounded）。

## 三、虚拟歌手设定（万相生成）

- 名字暂定：**MINA（ミナ）**，可改
- 画风：80 年代赛璐璐动画风，粗线条、喷枪高光、粉彩配色；**原创角色，不像任何真人**
- 造型：
  - 夜晚：一刀切长直发（ワンレン）+ 紫红色紧身连衣裙 + 金色大耳环 + 复古银色有线麦克风
  - 白天（副歌二）：垫肩粉彩西装外套 + 白色阔腿裤 + 墨镜架在头上
- 先出一张三视图定妆照，所有万相镜头都以它为首帧参考，保证前后一致
- 对口型：先测试万相的音频驱动模型（用分离出的人声 `stems_suno/htdemucs_ft/pop_1/vocals.wav` 驱动）。效果不好的话，就不做长时间的唱歌特写，改成舞蹈、走位、侧脸、远景，按节拍剪

## 七、实际制作记录（第一版粗剪）

### 演唱镜头：整段多机位

- 模型：`wan2.7-i2v`，首帧图 + 人声分轨（`stems_suno/htdemucs_ft/pop_1/vocals.wav`）驱动口型，每条 15 秒，1080P。`wan3.0` 不支持音频驱动。
- 每段副歌拍两条完整的同步演唱：近景（MCU）和全景（舞台或沙滩），剪辑时在两条之间切换，歌曲时间始终对齐，所以怎么切口型都不会错位。
- 夜晚副歌用 N1–N4，白天副歌用 D1–D4，最后副歌用 F1、F2（放在九宫格正中）。共 20 条万相镜头，清单在 `wan/shots.json` 和 `wan/shots2.json`。

### 影视素材

- 全部来自 YouTube 公开上传，原始信息（链接、标题、频道、上传日期）存放在 `footage/raw/*.json`，片尾的出处表就是从这里生成的。
- 用到的片段按标签放在 `footage/make_picks.py`，它会生成 `picks.json`。每个标签一组「素材 + 入点」，剪辑时轮流取用。
- 处理规则：4:3 画面里的黑边和电视台台标靠裁切去掉；字幕或水印太多的源不用（`disco_xenon`、`marunouchi_1989`、`bubble_short`）；`disco_nyny` 是 1987 年业余摄像机拍的，画面里的日期戳保留，当作年代细节。

### 渲染流程

`mv/edl.py` 生成剪辑表 `mv/edl.json`，`mv/render.py` 多进程逐帧合成：取画面 → 代码叠层 → 统一调色 `look/grade.py` → 双语字幕 `look/subtrack.py` → x264 编码 → 混入原曲。
