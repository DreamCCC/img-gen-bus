# 口播文稿去 AI 味清单

> 注意：本清单有几条和真实口播习惯冲突（自问自答、带路的话、刻意加“真人信号”），以 `口播风格指南.md` 为准。

规则改编自开源项目 [jiji262/humanizer-chinese](https://github.com/jiji262/humanizer-chinese)（MIT，36 条）和 [op7418/humanizer-zh](https://github.com/op7418/humanizer-zh)（31 条），两者都源自 Wikipedia《Signs of AI writing》。这里只保留口播科普最容易犯的几条。

写完初稿先跑一遍脚本，再按下面的清单人工过一遍，最后出声读一遍。

```bash
python creator-channel/tools/ai_lint.py creator-channel/ep01_4.8pct/B站版_文稿v2.md
```

## 必改（看到一次就改）

1. **铺垫代替陈述。** "先说一个很离谱的结论""这是什么概念？""那么问题来了"。删掉铺垫，直接说。自问自答全片最多留一两处。
2. **"不是 X，而是 Y"。** 直接说 Y。实在要对比，落点必须是具体事实。
3. **格言式金句。** "最好的那几扇门几乎没动""它搬了家"。换成具体陈述，比如"扩出来的名额，大头在地方院校和高职"。
4. **升华结尾。** 停在最后一个具体事实或一个具体问题上，不要拔高到时代命题。
5. **万能互动。** "扣 1""评论区说说你的看法""点赞关注"。要互动，就问一个从正文内容里长出来的具体问题。
6. **编造事实或经历。** 不能为了"人味"写"我当年……""我第一次读到时笑了"。观点可以加，经历和事实不能编。

## 看密度（成簇出现才改）

- **三段式。** "三件事""第一第二第三"。两项通常比三项自然；真有三条就别硬凑成排比。
- **逗号造势短句。** "报名费，五毛钱。""专科，比本科还多。"偶尔一句可以，满篇都是就成了 AI 腔。
- **一句一行、句长均匀。** 写成段落，长短句交替。
- **包装过的小标题。** "难的东西搬家了"→"清华扩了多少"。
- **引号滥用、破折号滥用。** 引号只用于引语和专名，破折号一段最多一处。
- **假口语。** "好家伙""说白了""实打实""家人们"。口语化靠句子结构，不靠口头禅。

## 保护（这些是真人信号，别改掉）

- 少见、具体、难编造的细节：当事人原话、具体日期、奇怪的小事。
- 明确的立场和理由："我对扩招的看法跟这个编者按不太一样。"
- 承认局限："这么比其实有点不公平。"
- 编辑上的犹豫："这个数我犹豫过要不要放。"
- 事实本身带出来的冷幽默："题目就是结论。"

## 终审

出声读一遍。像通稿、像课件、像励志视频旁白的段落，回炉重写。
